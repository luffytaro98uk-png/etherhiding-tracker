# Security Policy

## This Is a Defensive Security Tool

This project helps defenders identify and track EtherHiding malware
infrastructure on public blockchains. It does not perform any offensive
action, does not interact with victim machines, and does not attempt to
decrypt or reverse-engineer protected data.

## Reporting a Vulnerability

If you find a vulnerability in this tool itself, please report it privately.

**Do NOT open a public GitHub issue for security vulnerabilities.**

Email: [luffy.taro98uk@gmail.com]

Include a description of the issue, steps to reproduce, and any relevant
logs or output.

## Scope

In scope:
- Vulnerabilities in the tracker scripts themselves
- API key exposure or leakage
- Unintended code execution

Out of scope:
- The EtherHiding malware being tracked
- Blockchain RPC provider issues
- C2 domains operated by threat actors
